# Local Skill Exchange 🌐

## About
Local Skill Exchange is a platform where people can share their skills and learn new skills from others in their local community.

## Features
- 🔄 Exchange skills with others
- 🤝 Connect with local people
- 📚 Learn new skills
- 💡 Share your own skills
- 🌐 Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages
